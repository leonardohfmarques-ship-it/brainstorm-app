      BRAINSTORM

      Entrar com a chave do GitHub · uma vez por navegador

      1. 1No GitHub: Settings › Developer settings › Fine-grained tokens › Generate new token.
      2. 2Em Repository access, escolhe Only select repositories › brainstorm. Em Permissions: Contents › Read and write.
